# Guitar Bench Lab releases

This repository hosts verified Windows preview downloads for Guitar Bench Lab.

Releases are published from the private development workflow after its build, tests, package startup check, and asset checksum verification pass. Each Windows ZIP contains the executable and its matching GPLv3 source and dependency notices.

The first release has not been published yet. Preview builds are for evaluation; physical audio-interface and guitar measurements require separate validation. Updates currently require manually downloading and extracting a new ZIP.
